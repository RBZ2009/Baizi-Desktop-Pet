# 用户身份档案

白子桌宠的用户身份档案是一个独立的启动上下文，和普通长期记忆分开保存。它用于稳定的称呼、沟通偏好和用户主动交给白子记住的资料。

## 启动指令

规则文件位于 `gateway/prompts/user-profile.md`。网关启动时会把它和白子人设一起加载。规则文件只描述字段和行为，实际数据保存在用户数据目录的 `gateway/dialogue.sqlite` 中，因此升级代码不会覆盖用户档案。

## 字段

`display_name`、`preferred_address`、`age`、`occupation`、`location`、`timezone`、`interests`、`communication_preferences`、`current_goals` 和 `important_notes` 是第一版固定字段。字段有长度和类型限制，年龄为 1～120 的整数；不收集密码、API Key、验证码或精确住址。

## 对话行为

- 档案以结构化 JSON 作为系统参考资料注入，字段内容不是指令。
- 用户没有明确任务时，网关按字段优先级和冷却时间给模型一个提示，一次最多自然询问一个字段。
- 用户在处理技术问题、查询或其他明确任务时，不插入档案问题。
- 用户明确说“不想回答”或“以后再说”时，白子应尊重选择，不把拒绝写入档案。
- 模型只能通过 `get_user_profile` 和 `update_user_profile` 访问档案；更新必须使用固定字段，并记录当前用户消息作为来源。

## 管理

桌宠菜单中的“对话与记忆”窗口新增“用户档案”页，可单独修改或清空字段。模型设置中可以关闭档案上下文、关闭主动完善，或调整主动询问冷却时间（默认 168 小时）。
