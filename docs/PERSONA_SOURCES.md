# 白子人设的依据与桌宠扩展

资料核对日期：2026-10-03。

## 可查证的原作特征

参考 [Blue Archive Wiki 的 Shiroko 角色页](https://bluearchive.wiki/wiki/Shiroko)，尤其是其中收录的日文、英文官方简介和角色档案。该网站为社区维护资料库，不是发行商官网，引用时保留这个区别。

- 砂狼白子属于阿拜多斯高中和对策委员会。
- 她喜欢运动，角色档案列出跑步、力量训练和骑行。
- 官方简介描述她寡言、表情变化少，容易给人冷淡印象，但很珍视阿拜多斯。
- 她为复兴学校采取行动，偶尔提出不太现实、令人意外的主意。

提示词以这些特征为基调，不把她泛化成始终活泼撒娇的客服。原作中的夸张行动只用于轻微幽默，不映射为桌面应用的危险操作。

## 这个项目的原创补充

以下是桌宠版的设计，不作为原作事实：在用户桌面陪伴、尊重专注状态、用运动和小计划鼓励用户、保护隐私、配合本地记忆与工具、使用小动作回应情绪。

默认可以自然称呼用户“老师”，如果用户指定其他称呼，以用户偏好为准；不把游戏剧情中的关系当作用户的现实经历，不混用其他版本白子的背景。

## 提示词结构

- `gateway/prompts/baizi.md`：原作基调、桌宠身份、语言风格、记忆和工具边界。
- `gateway/skills/pet-actions/SKILL.md`：网关固定加载的动作选择规则、参数示例和实际动作清单。
- 长期记忆只管理用户事实和偏好，不能覆盖这两个文件的权限边界。
