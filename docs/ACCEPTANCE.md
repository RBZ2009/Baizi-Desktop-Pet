# 源码版验收

本轮按阶段提交并推送，不生成新的 `.app`。退出此前运行的 Electron/桌宠实例后，在项目根目录运行 `npm start`，或双击 `start.command`；原有 `dist/` 应用仍然是旧版本。

## 回复与输入框

- 点击头部打开、再次点击关闭，输入框保持独立并随输入增长。
- 发送一段较长文字，确认回复气泡逐段更新，较长回复可以滚动阅读。
- 把角色拖到屏幕顶部、左右边缘或另一块屏幕，检查气泡是否留在可用区域，并始终在角色前方。
- 输入框中按 Escape 取消；立即发送另一条消息，确认旧文字、旧声音和关闭定时器不会覆盖新回复。

## 工具与动作

在“对话与记忆 → 模型设置”确认已保存模型，开启工具。

| 示例输入 | 预期行为 |
| --- | --- |
| 现在上海几点？ | 使用时间工具，返回指定时区时间 |
| 帮我看看上海今天的天气 | 显示查询状态，再引用天气地点、时间和单位 |
| 搜索 Open-Meteo 的天气 API 文档，给我链接 | 展示搜索摘要来源；验证码或失败时明确告知 |
| 点一下头，再跟我打招呼 | 点头或模型未就绪时适当忽略，最终回复不含工具 JSON |
| 跳个舞给我看看 | 短暂跳舞后恢复待机 |
| 你先安静待一会儿 | 选择待机或安静陪伴，不持续刷动作 |

命令诊断默认关闭。主动打开对应开关后，可问“查看这个项目的 git 状态”；仅执行固定命令。要求删除文件、执行 shell 或运行项目脚本时，应明确说明不支持，不能假报成功。

工具需要模型支持标准函数调用；不支持的模型接口会回退为文字回答。小上下文窗口不足以容纳人设和工具时，本轮不会启用工具。网络查询依赖本机能访问 Open-Meteo 和 DuckDuckGo。

## 记忆与语音

告诉白子一个稳定偏好，查看长期记忆页面；新会话和重启后确认能使用正确的记忆。手动纠正/删除功能沿用原实现。

本轮语音范围为研究与架构方案，仍使用 macOS 系统声音；没有开启麦克风、实时语音通话、录音或新供应商 API。后续方案见 `VOICE_ARCHITECTURE.md`。
