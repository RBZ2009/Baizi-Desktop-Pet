# Legacy TTS experiments

These Python examples are historical experiments for Aliyun/Qwen streaming TTS. The Electron app does not import, execute, or package them; current system speech uses `speech-service.js` and the future realtime voice integration will live behind the local gateway.

- `official-qwen/` contains the duplicated upstream-style realtime sample.
- The root files contain earlier standalone probes and wrappers.
- `requirements.txt` lists dependencies for these samples only.

Keep API keys in environment variables if these examples are run manually. They are retained for reference and are not part of the application runtime.
