对话与记忆

白子的人设与记忆在本机管理，回复由你配置的模型 API 生成。

填写兼容接口的基础地址（通常以 /v1 结尾）。

天气使用 Open-Meteo，搜索使用 DuckDuckGo；查询内容会发送给对应服务。命令诊断仅允许固定命令，结果会发送给模型。命令默认关闭，不读取文件正文、不执行项目脚本。

API Key 使用系统安全存储加密。选入上下文的对话和记忆会发送给模型供应商。

重要事实会在回复后自动提取。这里可以直接添加、纠正或删除；删除会阻止旧记录重新写入同一记忆。删除记忆不会删除聊天原文，旧会话仍可能提及；开启新会话后只会召回未删除的记忆。

新会话清空短期上下文，长期记忆仍保留。切换会话会停止当前回复和播报。
